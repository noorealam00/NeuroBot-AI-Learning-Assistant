
# NeuroBot — AI Learning Assistant

NeuroBot is an ANN-powered AI learning assistant built with Python and Flask. It uses Natural Language Processing (NLP) and a Scikit-learn MLPClassifier to recognise user intents and generate relevant responses.

## Features
- Intent classification using a neural network
- Bag-of-Words text representation
- Multiple predefined intents and responses
- Confidence threshold for unknown questions
- Web-based chat interface

## Technologies
- Python
- Flask
- Scikit-learn
- NumPy
- HTML, CSS and JavaScript

## Installation

1. Install Python.
2. Clone or download this repository.
3. Install dependencies:

   pip install -r requirements.txt

## Train the Model

Run:

   python train.py

## Start the Application

Run:

   python app.py

Open the local address printed in your terminal
in your web browser.

## Notes
The model's reported training accuracy is not the
same as its performance on unseen test data.
